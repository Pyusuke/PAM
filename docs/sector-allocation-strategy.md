# セクター分散戦略（日本株・バランス型・100万円未満）

## あなたの投資プロファイル

| 項目 | 内容 |
|------|------|
| 投資対象 | 日本株のみ |
| 投資スタイル | 配当 + 値上がりのバランス型 |

| 目標銘柄数 | 5〜8銘柄 |
| 目標配当利回り | 3.5%〜4.5%（ポートフォリオ全体） |

## 推奨セクター配分（5〜8銘柄の場合）

100万円未満の予算では銘柄数に限りがあるため、**異なる景気感応度**のセクターを組み合わせることが重要です。

### コア（必須）: 3〜4銘柄 ／ 全体の50〜60%

安定配当かつ値上がりも期待できるセクターです。

| セクター | 配分目安 | 選ぶ理由 |
|----------|---------|---------|
| **通信** | 15〜20% | 安定したキャッシュフロー。増配傾向。ディフェンシブ性が高い |
| **総合商社** | 15〜20% | 資源＋非資源の多角経営。増配＋自社株買いに積極的。値上がり益も期待 |
| **金融（メガバンク・保険）** | 15〜20% | 金利上昇局面で業績改善。PBR改善の取り組みが株価の追い風 |

### サテライト（補完）: 2〜4銘柄 ／ 全体の40〜50%

コアと異なる値動きをするセクターで分散効果を高めます。

| セクター | 配分目安 | 選ぶ理由 |
|----------|---------|---------|
| **製造（化学・機械）** | 10〜15% | 景気回復局面で値上がりが期待。グローバル展開で成長性あり |
| **インフラ・建設** | 10〜15% | ディフェンシブ。国土強靭化・再開発の恩恵 |
| **日用品・食品** | 10〜15% | 景気に左右されにくい。連続増配企業が多い |
| **リース・その他金融** | 10〜15% | 高配当かつ多角経営で安定。株価も成長傾向 |

## セクターの組み合わせ例

### パターンA: 安定重視（5銘柄・約80〜100万円）

```
通信      ──── 1銘柄 (20%)  ← ディフェンシブ
総合商社  ──── 1銘柄 (20%)  ← バランス
金融      ──── 1銘柄 (20%)  ← 景気敏感
日用品    ──── 1銘柄 (20%)  ← ディフェンシブ
リース    ──── 1銘柄 (20%)  ← バランス
```

**特徴**: ディフェンシブ40% + バランス40% + 景気敏感20%。守り重視で安定配当を確保しつつ、金融・商社で値上がりも狙う。

### パターンB: 成長も狙う（6銘柄・約80〜100万円）

```
通信      ──── 1銘柄 (17%)  ← ディフェンシブ
総合商社  ──── 1銘柄 (17%)  ← バランス
金融      ──── 1銘柄 (17%)  ← 景気敏感
製造      ──── 1銘柄 (17%)  ← 景気敏感
インフラ  ──── 1銘柄 (16%)  ← ディフェンシブ
リース    ──── 1銘柄 (16%)  ← バランス
```

**特徴**: ディフェンシブ33% + バランス33% + 景気敏感34%。よりバランスが取れた構成。製造セクターで値上がり益を狙う。

### パターンC: 少額スタート（5銘柄・約50万円）

```
通信      ──── 1銘柄 (20%)  ← ディフェンシブ
総合商社  ──── 1銘柄 (20%)  ← バランス
金融      ──── 1銘柄 (20%)  ← 景気敏感
製造      ──── 1銘柄 (20%)  ← 景気敏感
食品      ──── 1銘柄 (20%)  ← ディフェンシブ
```

**特徴**: 1銘柄あたり約10万円。単元（100株）で買える銘柄を中心に選定。資金が増えたらセクターを追加していく。

## セクター分散のポイント

### 景気感応度で分ける

セクターは「景気にどう反応するか」で3タイプに分けられます。

```
ディフェンシブ（守り）     バランス（中間）        景気敏感（攻め）
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ 通信           │   │ 総合商社       │   │ 金融（銀行）   │
│ 食品・日用品   │   │ リース         │   │ 製造（化学等） │
│ インフラ       │   │ 保険           │   │ 不動産         │
│ 電力・ガス     │   │                │   │ 自動車関連     │
└──────────────┘   └──────────────┘   └──────────────┘
景気悪化に強い         どちらにも対応          景気回復で大きく伸びる
配当は安定             配当+成長               値上がり益も期待大
```

**配当+値上がりのバランス型**なら、この3タイプを均等に近い比率で持つのが理想的です。

### 避けたい偏り

| 偏りパターン | リスク |
|-------------|-------|
| 金融ばかり3銘柄 | 金利環境の変化で全滅する可能性 |
| 景気敏感ばかり | 景気後退で配当も株価も下落 |
| ディフェンシブばかり | 安定するが値上がりが小さい |
| 同じ業種の類似企業 | 分散効果がほとんどない |

## 次のステップ

1. **上記パターンA〜Cから、自分に合いそうなパターンを選ぶ**
2. **各セクターで具体的な銘柄候補をリストアップする**
3. **スクリーニングチェックリストで各銘柄を評価する**
4. **ポートフォリオテンプレートに記入して全体のバランスを確認する**
