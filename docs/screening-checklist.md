銘柄を購入する前に、以下のチェックリストで確認しましょう。

## Step 1: 配当の質を確認する

| チェック項目 | 基準 | 実際の値 | 合否 |
|-------------|------|---------|------|
| 配当利回り | 3.0%以上 | ___% | [ ] |
| 配当利回り | 6.0%未満（高すぎないか） | ___% | [ ] |
| 配当性向 | 30%〜60% | ___% | [ ] |
| 過去10年の配当推移 | 減配なし or 増配傾向 | | [ ] |
| 配当方針 | 累進配当 / DOE基準 / 下限あり | | [ ] |

### 確認ポイント
- IR BANKで過去10年の配当推移をグラフで確認
- 中期経営計画で配当方針（累進配当・配当性向目標など）を確認
- 記念配当を除いた「普通配当」で利回りを計算する

---

## Step 2: 業績の安定性を確認する

| チェック項目 | 基準 | 実際の値 | 合否 |
|-------------|------|---------|------|
| 売上高推移（過去5年） | 安定 or 成長 | | [ ] |
| 営業利益推移（過去5年） | 安定 or 成長 | | [ ] |
| 営業利益率 | 業界平均以上 | ___% | [ ] |
| EPS推移（過去5年） | 安定 or 成長 | | [ ] |
| 来期業績予想 | 増益 or 横ばい | | [ ] |

### 確認ポイント
- 景気に大きく左右されるかどうか（シクリカル銘柄の見極め）
- コロナショック時（2020年）の業績がどうだったか
- 来期のコンセンサス予想と会社予想の乖離

---

## Step 3: 財務の健全性を確認する

| チェック項目 | 基準 | 実際の値 | 合否 |
|-------------|------|---------|------|
| 自己資本比率 | 40%以上 | ___% | [ ] |
| 有利子負債比率 | 同業比較で高すぎないか | ___% | [ ] |
| 営業CF | 安定的にプラス | | [ ] |
| FCF（フリーCF） | 安定的にプラス | | [ ] |
| 現金同等物 | 十分な水準 | | [ ] |

### 確認ポイント
- 金融（銀行・保険）やリースは自己資本比率が低いのが一般的なので、同業比較で判断
- 営業CFが安定してプラスかどうか（利益が出ていてもCFが出ていない場合は注意）
- FCFが配当総額を上回っているか

---

## Step 4: バリュエーション（割安度）を確認する

| チェック項目 | 基準 | 実際の値 | 合否 |
|-------------|------|---------|------|
| PER | 15倍以下（目安） | ___倍 | [ ] |
| PBR | 業界平均以下 | ___倍 | [ ] |
| ROE | 8%以上 | ___% | [ ] |
| 過去平均PERとの比較 | 割安圏にあるか | | [ ] |

### 確認ポイント
- PER/PBRは業界によって水準が異なるため、必ず同業比較する
- 過去5年の平均PERと比較して割安かどうか
- ROEが高すぎる場合（20%以上）、レバレッジによるものでないか確認

---

---

## 使い方

1. 気になる銘柄ごとにこのチェックリストをコピーして使用する
2. すべてのStepを順番にチェックする
3. 1つでもFailがある場合は、そのリスクを受け入れられるか慎重に検討する
4. 総合判定で「購入候補」となった銘柄のみ、ポートフォリオへの組み入れを検討する
