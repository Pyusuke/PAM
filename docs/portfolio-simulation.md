## この1年間で得られた教訓

### うまくいった点

1. **JTの配当貢献が大きい**: 配当金全体の約5割をJT1銘柄で稼いでいる
2. **金融セクターの値上がり**: 三菱UFJは金利上昇を追い風に+62%と大きく上昇
3. **商社の株価成長**: 三井物産は+74%の値上がりで含み益トップ
4. **セクター分散が機能**: 全5銘柄がプラスリターン

### 注意すべき点

1. **NTTの貢献度が小さい**: 100株15,000円と投資額自体が少ないため、配当・値上がりとも限定的
2. **JTへの依存度が高い**: 投資額の約41%、配当の約51%がJT1銘柄に集中
3. **この1年は相場環境が良かった**: 日本株全体が上昇基調だったため、今後も同じリターンが得られるとは限らない
4. **含み益は「未実現」**: 売却するまで利益は確定しない。株価は下落する可能性もある

---

> **免責事項**: 本シミュレーションは過去のデータに基づく概算です。株価は概算値を使用しており、
> 実際の取引価格・手数料・税金とは異なります。過去の実績は将来のリターンを保証するものではありません。

### 案Cが上回った要因

この1年間に限れば、案Cポートフォリオがインデックスを**約22ポイント上回り**ました。

1. **銘柄選定が好結果**: 三井物産(+74%)・三菱UFJ(+62%)・JT(+42%)の3銘柄が日経平均(+37%)を大きく上回った
2. **金利上昇の恩恵**: 金融セクター（三菱UFJ）が日経平均全体より大きく上昇
3. **商社・たばこの好業績**: 資源高・海外事業好調で個別銘柄の上昇幅が大きかった
4. **配当金の上乗せ**: インデックスは分配金を再投資するが、個別株は別途現金で約4.6万円の配当を受け取れた

### ただし注意すべき点

| 観点 | 案C（個別株） | eMAXIS Slim |
|------|-------------|-------------|
| **手間** | 銘柄選定・決算チェックが必要 | 買って放置でOK |
| **分散度** | 5銘柄・4セクター | **225銘柄に自動分散** |
| **リスク** | 個別銘柄リスクあり（減配・不祥事等） | **市場全体に分散** |
| **再現性** | この結果が毎年続くとは限らない | 市場平均を安定的に取れる |
| **少額投資** | 単元株(100株)単位の制約あり | **100円から購入可能** |
| **コスト** | 売買手数料（証券会社による） | **信託報酬 年0.143%のみ** |
| **NISA** | 成長投資枠で購入可能 | **つみたて投資枠でも購入可能** |

### どちらを選ぶべきか

```
「手間をかけず市場平均を取りたい」 → eMAXIS Slim 日経平均
    ✅ 225銘柄に自動分散
    ✅ 100円から積立可能
    ✅ つみたてNISA対応
    ✅ 銘柄選定・管理の手間ゼロ

「配当金を実際に受け取りたい」 → 案C（個別高配当株）
    ✅ 年4回のキャッシュフロー（約4.6万円/年）
    ✅ 銘柄選定次第でインデックスを上回る可能性
    ✅ 増配による利回り向上が期待できる
    ⚠️ 銘柄分析・管理の手間がかかる
    ⚠️ インデックスを下回るリスクもある

「迷うなら両方」 → コア・サテライト戦略
    資産の60〜70%: eMAXIS Slim（コア・安定運用）
    資産の30〜40%: 個別高配当株（サテライト・配当狙い）
```

### この比較から分かること

#### 1. 相場環境で結果は大きく変わる

- 横ばい相場（2024/2→2025/2）: 案Cの超過リターンは**わずか+1.2pt**

- **高配当個別株がインデックスに勝てるかは、その年の相場環境に大きく左右される**

#### 2. 横ばい・下落相場では「配当金」が生命線

- 含み益はわずか+26,700円（+2.0%）
- **配当金+47,815円（+3.7%）がリターンの64%を占めた**
- 配当金がなければ、eMAXIS Slimにほぼ負けていた

#### 3. 個別株にはリスクもある

- **NTTは-18.0%の大幅下落**（2024年は株価が低迷した年）
- **三井物産も-7.6%のマイナス**
- 5銘柄中2銘柄がマイナスだった（インデックスなら個別リスクは分散される）

### この比較から分かる重要な教訓

#### 1. 「最強の投資先」は毎年変わる

```
期間1（2024/2→2025/2）: S&P500 (+20%) > オルカン (+18%) >> 案C (+5.7%) > 日経平均 (+4.5%)
期間2（2025/2→2026/2）: 案C (+58.7%) >> 日経平均 (+37.1%) >> S&P500 (+18%) ≒ オルカン (+17%)
```

- 期間1ではS&P500が圧倒的な勝者、オルカンも僅差で続いた
- 期間2では逆転し、日本株が海外インデックスを大幅に上回った
- **「S&P500やオルカンに入れておけば安心」は常に正しいわけではない**

#### 2. 為替リスクは無視できない

S&P500・オルカンともに為替ヘッジなしのため:
- **円安局面（期間1）**: 為替が+2%のボーナスとなりリターン上乗せ
- **円高局面（期間2）**: 為替が-1.3%のペナルティとなりリターン圧縮
- 日銀の利上げが続けば、円高リスクはさらに高まる可能性がある

#### 3. オルカン vs S&P500: 分散効果は限定的

- 2つの期間でオルカンとS&P500のリターン差は**わずか2pt以内**
- オルカンの約60%が米国株のため、S&P500と非常に近い値動きをする
- 欧州・新興国の比率が分散効果を生むが、リターン差への影響は小さい
- **「S&P500かオルカンか」よりも「日本株 vs 海外株」の配分が重要**

#### 4. 日本の高配当個別株の強み

- 2年通算では案Cが**全戦略の中でトップ**（+67.7%）
- 横ばい相場でも配当金がクッション（期間1で+3.7%のインカム）
- 上昇相場では個別銘柄の選定効果が最大化

#### 5. ただし注意点も

- この2年間は案Cの銘柄選定が「たまたま」うまくいった面もある
- NTTは2年間で大きく下落（-18%+3.3%）、銘柄選定を間違えれば逆の結果になり得た
- **過去2年間が今後も続く保証はない**
