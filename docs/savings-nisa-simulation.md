## 10. リスクと注意点

### 貯金が大幅に減少するリスク

```
⚠️  このプランでは2030年10月に貯金が28万円まで減少します

    ・急な出費（医療費、冠婚葬祭、家電故障等）に対応できない可能性
    ・収入が途絶えた場合のバッファがほぼゼロ
    ・精神的な不安が大きくなる可能性
```

### 対策案

#### 案1: 生活防衛資金を確保する（推奨）

最低でも**生活費3〜6ヶ月分**を貯金に残す設計に変更:

| 生活防衛資金 | 成長投資を減額 | NISA完了時期 | 最低貯金残高 |
|------------|-------------|-----------|-----------|
| 100万円確保 | 月17万に減額 | 2031年6月頃 | 約100万円 |
| 200万円確保 | 月14万に減額 | 2032年2月頃 | 約200万円 |
| 300万円確保 | 月11万に減額 | 2033年3月頃 | 約300万円 |

#### 案2: ボーナス・臨時収入で成長投資枠を一括投資

毎月の成長投資額を抑え、ボーナス時にまとめて投資することで
月々の貯金の減り方を緩やかにできる。

#### 案3: 段階的に投資額を調整

```
2026〜2027年: 成長投資 月20〜24万（貯金に余裕があるうちに積極投資）
2028〜2029年: 成長投資 月15万（貯金が減ってきたら減額）
2030年〜:    成長投資 月10万（残りを慎重に埋める）
```

### その他の注意点

1. **余剰収入の変動**: 収入や支出が変動する可能性がある。余裕がなくなったら成長投資を一時停止する判断も重要
2. **NISA内の運用損**: 含み益を考慮していないが、実際には元本割れのリスクもある。ただしNISA枠は簿価で管理されるため、枠の消化には影響しない
3. **制度変更リスク**: 将来的にNISA制度が変更される可能性はゼロではない
4. **成長投資枠の商品選択**: 個別株か投資信託かで管理の手間やリスクが大きく異なる
