## 高配当株投資とは

企業が利益の一部を株主に還元する「配当金」に着目した投資手法です。株価の値上がり益（キャピタルゲイン）ではなく、定期的に受け取る配当金（インカムゲイン）を主な収益源とします。

### メリット

- **安定した収入源**: 保有しているだけで定期的に配当金を受け取れる
- **精神的な安定**: 株価変動に一喜一憂しにくい
- **複利効果**: 配当金を再投資することで資産が加速度的に増える
- **インフレ対策**: 増配企業なら配当が年々増えていく

### デメリット

- **株価下落リスク**: 配当以上に株価が下がる可能性がある
- **減配・無配リスク**: 業績悪化で配当が減る、なくなる可能性がある
- **成長機会の逸失**: 高配当株は成熟企業が多く、株価の大幅な上昇は期待しにくい
- **税金**: 配当金には約20%の税金がかかる（NISA口座を除く）

## 始める前に知っておくべきこと

### 必要な準備

1. **証券口座を開設する**
   - ネット証券がおすすめ（SBI証券、楽天証券、マネックス証券など）
   - 手数料が安い証券会社を選ぶ

2. **NISA口座を活用する**
   - 新NISA（2024年〜）の「成長投資枠」で高配当株を購入すると配当金が非課税
   - 年間240万円まで（成長投資枠）
   - 非課税保有限度額：1,200万円（成長投資枠）

3. **投資資金を用意する**
   - 生活防衛資金（生活費6ヶ月〜1年分）を確保した上で投資する
   - 余裕資金で行うこと

### 心構え

- 一攫千金を狙わない
- 長期保有が前提（最低でも3〜5年以上）
- 分散投資を徹底する
- 定期的に銘柄の業績をチェックする

## 銘柄選定の基準

高配当株を選ぶ際の基本的なフィルター条件です。

### 必須条件

| 条件 | 基準 |
|------|------|
| 配当利回り | 3.0%以上（目安） |
| 配当性向 | 30%〜60%が理想（高すぎると危険） |
| 連続増配 or 安定配当 | 過去10年以上減配なし |
| 自己資本比率 | 40%以上（財務の安全性） |
| 営業利益率 | 業界平均以上 |

### 望ましい条件

| 条件 | 基準 |
|------|------|
| 時価総額 | 1,000億円以上（安定性） |
| フリーキャッシュフロー | 安定的にプラス |
| ROE | 8%以上 |
| PER | 15倍以下 |
| PBR | 割安圏にあること |
| 配当方針 | 累進配当や下限配当の明示 |

## 重要な財務指標

### 配当利回り

```
配当利回り(%) = 1株あたり年間配当金 ÷ 株価 × 100
```

- 3%〜5%が高配当の目安
- **5%を超える場合は注意**: 株価下落による見かけ上の高利回り（罠銘柄）の可能性がある
- 過去の配当推移と合わせて確認すること

### 配当性向

```
配当性向(%) = 1株あたり配当金 ÷ 1株あたり利益(EPS) × 100
```

- 30〜60%が健全な範囲
- 70%以上は利益のほとんどを配当に回しており、持続性に懸念
- 100%以上は利益以上に配当を出しており、危険信号

### 自己資本比率

```
自己資本比率(%) = 自己資本 ÷ 総資産 × 100
```

- 40%以上が目安（業種による）
- 銀行・不動産など一部業種は低くなる傾向があるため、同業比較が重要

### ROE（自己資本利益率）

```
ROE(%) = 当期純利益 ÷ 自己資本 × 100
```

- 8%以上が目安
- 高すぎる場合はレバレッジ（借入）で高めている可能性もあるため注意

### フリーキャッシュフロー(FCF)

```
FCF = 営業キャッシュフロー − 設備投資額
```

- 配当はFCFから支払われるため、安定的にプラスであることが重要
- FCF < 配当総額が続くと、いずれ減配のリスクがある

## セクター分散の考え方

特定の業種に偏ると、業界全体の不況で大きな影響を受けます。以下のようにセクターを分散させましょう。

### 日本株 高配当が期待できるセクター

| セクター | 特徴 | 代表的な業種 |
|----------|------|-------------|
| 通信 | 安定的なキャッシュフロー | 携帯キャリア |
| 金融 | 金利環境に左右される | メガバンク、保険、リース |
| 商社 | 資源価格に連動 | 総合商社 |
| エネルギー | 資源価格に連動 | 石油元売り、電力・ガス |
| 製造 | 景気循環の影響あり | 化学、機械、自動車部品 |
| インフラ | ディフェンシブ | 鉄道、電力 |
| 日用品 | ディフェンシブ | 食品、トイレタリー |

### 分散の目安

- **最低10銘柄以上**に分散
- **5セクター以上**に分散
- 1銘柄あたりポートフォリオの**10%以下**に抑える

## 買い方の戦略

### 一括投資 vs 分割投資

| 方法 | メリット | デメリット |
|------|---------|-----------|
| 一括投資 | 上昇局面で最大の利益 | 高値掴みのリスク |
| 分割投資（時間分散） | 購入単価を平均化できる | 上昇局面では機会損失 |

**初心者には分割投資（ドルコスト平均法）を推奨**

### 購入タイミングのヒント

- **権利確定日の2〜3ヶ月前**: 配当狙いの買いが入る前に購入
- **権利落ち後の下落時**: 配当分の株価下落で割安に買える可能性
- **市場全体の調整局面**: 業績に問題がないのに下がっている銘柄を狙う
- **決算発表後**: 好業績なのに売られた場合はチャンスの可能性

### 注意点

- 「配当利回りが高い」だけで飛びつかない
- 権利確定日直前の購入は高値掴みになりやすい
- 一度に全資金を投入しない

## リスク管理

### 売却を検討すべきタイミング

- **減配が発表された**（一時的な要因か構造的な問題か見極める）
- **配当性向が80%を超えた**（持続性に疑問）
- **事業環境が根本的に変化した**（規制変更、技術革新による陳腐化など）
- **不祥事・ガバナンス問題が発生した**
- **より良い投資先が見つかった**

### やってはいけないこと

- 含み損を理由に損切りを躊躇し続ける（塩漬け）
- ナンピン買い（下落中に買い増し）を安易にする
- 配当利回りだけで銘柄を選ぶ
- 1銘柄に集中投資する
- 借金（信用取引）で高配当株を買う

## 税金について

### 配当金にかかる税金

| 口座種類 | 税率 |
|----------|------|
| 特定口座（源泉徴収あり） | 20.315%（所得税15.315% + 住民税5%） |
| NISA口座 | 非課税 |

### 配当控除

- 確定申告で「総合課税」を選択すると、配当控除が受けられる
- 課税所得が695万円以下の場合、総合課税が有利になることが多い
- ただし、住民税は申告不要制度を選択するなど注意が必要

### NISAの活用

- **高配当株投資とNISAは相性が良い**
- 成長投資枠（年240万円）で高配当株を購入
- 配当金の受取方法は「株式数比例配分方式」にしないと非課税にならない点に注意

## よくある失敗パターン

### 1. 利回りの罠

> 配当利回り8%! → 実は業績悪化で株価が暴落しているだけ → その後減配 → さらに株価下落

**対策**: 利回りだけでなく、業績・財務状況を必ず確認する

### 2. 集中投資

> 配当利回りが高い銘柄1つに全資金投入 → 減配発表 → 大損

**対策**: 最低10銘柄、5セクター以上に分散する

### 3. 高値掴み

> 権利確定日直前に購入 → 権利落ちで株価下落 → 配当以上の含み損

**対策**: 権利確定日から逆算して余裕をもって購入する

### 4. 情報のアップデート不足

> 購入後に放置 → 業績悪化に気づかず → 減配

**対策**: 四半期決算ごとに業績をチェックする
