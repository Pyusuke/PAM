## 配当金の入金スケジュール（目安）

日本株の配当は主に以下のタイミングで入金されます。

| 決算月 | 権利確定日 | 中間配当入金 | 期末配当入金 |
|--------|-----------|-------------|-------------|
| 3月決算 | 3月末・9月末 | 12月頃 | 6月頃 |
| 12月決算 | 12月末・6月末 | 9月頃 | 3月頃 |
| 9月決算 | 9月末・3月末 | 6月頃 | 12月頃 |

## 定期チェックリスト

### 四半期ごとのチェック（決算発表後）

- [ ] 各銘柄の決算内容を確認
- [ ] 業績予想の修正がないか確認
- [ ] 配当予想の修正がないか確認
- [ ] 配当性向が適正範囲内か確認
- [ ] セクター配分が偏っていないか確認

### 年次チェック

- [ ] 各銘柄の年間配当実績を記録
- [ ] ポートフォリオ全体の利回りを計算
- [ ] NISA枠の使用状況を確認
- [ ] リバランス（配分調整）の要否を検討
- [ ] 翌年の投資計画を立てる
